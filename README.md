# ORMs Erros Comuns

Projeto da talk usando backend em Django + DRF e frontend em React (Vite).

## Backend (Django + DRF)

- Instalar dependências: `uv sync`
- Rodar servidor: `uv run python manage.py runserver`
- Endpoint API: `GET /api/hello/`

## Frontend (React)

- `cd frontend && npm install`
- `npm run dev`

## Testes

- `uv run pytest`

## Slides (Slidev)

- Arquivo: `slides/slides.md`
- Instalar dependências: `just slides-install`
- Rodar em modo desenvolvimento: `just slides`
- Build de produção: `just slides-build`
- Abrir no navegador: `http://localhost:3030`
